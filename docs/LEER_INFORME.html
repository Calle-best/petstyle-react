PetStyle · Planificación del proyecto

Avance del proyecto web con React y Tailwind CSS. Documento elaborado a partir del proyecto entregado y de los requisitos de las dos fotografías. Los objetivos y requisitos siguientes formalizan el alcance que ya implementa la aplicación; el equipo puede adaptar los datos académicos de portada.

Pregunta 1. Definición y objetivos

Nombre: PetStyle – Moda para Mascotas.

Descripción y propósito: catálogo web de ropa y accesorios para perros y gatos. Permite explorar colecciones, comparar precios, consultar tallas y preparar un pedido que se coordina por WhatsApp. Es un prototipo académico; el carrito no cobra y los formularios no envían correos.

Público objetivo: personas responsables de perros y gatos, principalmente compradores en Perú, que consultan productos desde el teléfono o una computadora y necesitan orientación para elegir una talla.

Necesidad: reunir productos, precios, disponibilidad y medidas en una interfaz organizada, para reducir la búsqueda dispersa y facilitar la consulta antes de pedir.

Objetivo general: desarrollar una aplicación web responsive con React, Vite y Tailwind CSS que facilite la consulta de moda y accesorios para mascotas y la preparación de pedidos por WhatsApp.

Objetivos específicos:

  1. Organizar un catálogo dinámico de al menos 10 productos mediante una API, con categorías, buscador, filtros y ordenamiento.
  2. Ofrecer navegación consistente entre inicio, catálogo, detalle, tallas y contacto, usando rutas y componentes reutilizables.
  3. Implementar carrito con persistencia local y formularios validados, con una interfaz usable en móvil, tablet y escritorio.

Preparación local

Instala Node.js 24 LTS o una versión compatible de Node a partir de 22.14. Abre una terminal dentro de petstyle/:

npm ci
npm run dev

npm run dev inicia JSON Server en http://localhost:3001/products y Vite en http://localhost:5173. Para evaluar el requisito de JSON Server, muestra la respuesta de la primera dirección y luego el catálogo de 52 productos en la web.

npm run lint
npm test
npm run build

Importante sobre npm run preview: muestra la compilación estática en tu equipo, pero no ejecuta las funciones de Vercel/Netlify. Para probar solo esa compilación localmente contra JSON Server, inicia npm run api en otra terminal y compila con una variable temporal en PowerShell:

$env:VITE_API_URL = 'http://localhost:3001'
npm run build
Remove-Item Env:VITE_API_URL
npm run preview

Antes de publicar, ejecuta otra vez npm run build sin esa variable. No configures localhost como API en el hosting. En un despliegue normal se utiliza /api/products del mismo dominio. Puedes compilar de nuevo sin variables para regenerar la versión que va al hosting.

Despliegue: elegir una plataforma

Vercel

Importa el repositorio de PetStyle como proyecto Vite. Si el repositorio contiene una carpeta exterior, selecciona petstyle como directorio raíz. Comando de build: npm run build; salida: dist; versión de Node: 24. api/products.js se encarga del endpoint; vercel.json dirige las rutas de la web a index.html y deja el prefijo /api/ fuera de esa regla.

Netlify

Importa el repositorio por Git para que Netlify ejecute la compilación y empaquete las funciones. netlify.toml define npm run build, la carpeta dist, Node 24 y netlify/functions como carpeta de funciones. public/_redirects envía /api/products a la función de productos antes de la regla de rutas de React. Subir únicamente dist mediante arrastrar y soltar no despliega las funciones.

La documentación oficial de Vite, Vercel y Netlify sirve como referencia para compilación y rutas. La ejecución remota debe comprobarse después de crear el despliegue.
